# 整蛊老师模拟器 v0.7

一款**单文件、离线可玩**的课堂整蛊小游戏。上课时抓紧时间恶作剧赚金币，下课铃一响就冲进课间商城补货，然后继续下一节课的快乐循环。

v0.7 加入了一整套**账号与存档体系**：首次打开先起个名字，金币和道具按账号隔离保存在本机；还可以生成 **6 位存档码**，换设备也能把进度搬过去。同时新增 **7 大玩法**——粉笔狙击、多老师轮换、课堂 QTE、粒子光波、同学告密、周末补课、食堂陷阱，以及一个藏在快捷键后面的**上帝管理后台**。

> 纯属虚构娱乐。游戏中的老师没有受到真实伤害，只损失了一点发型和尊严。

## 快速开始

1. **双击** `v0.7.html`，用浏览器打开（支持 `file://` 直接打开，不需要服务器）
2. 第一次进入会弹窗要求输入**用户名**（1–12 个字符），点「进入游戏」
3. 选择难度，点击「开始上课」
4. 靠近老师，用拳头或道具整蛊他
5. 上课过程中会轮换老师、触发 QTE、粉笔狙击、告密和食堂事件
6. 下课铃响后，在 1 分钟课间商城购买新道具
7. 开始下一节课，继续赚金币

想换玩法？标题页点 **📚 周末补课模式** 或 **🏃 休闲模式**；想管理账号和存档码，点右上角 **👤 账号胶囊**。

**不需要安装、不需要联网、不需要启动服务器**，所有内容都在一个 HTML 文件里。联网只在「上传存档码」时使用，且失败不影响本地存档。

## 👤 账号系统（v0.7）

### 首次登录

* 第一次打开游戏时必须输入用户名，空名字会被拒绝。
* 点「进入游戏」后，用户名写入浏览器 `localStorage`，下次打开**自动登录**，不再询问。
* 用户名最长 12 个字符，会过滤掉 `< > &` 等特殊字符和多余空格。
* 右上角新增 **账号胶囊**，显示当前用户名；点它可以打开「账号与存档」面板。

### 按用户名隔离

* 每个账号的元数据、局内进度和额外设置分开保存，互不影响。
* 关键存储键：

| 键名  | 内容  |
| --- | --- |
| `prankTeacher.v7.user` | 当前登录的用户名 |
| `prankTeacher.v7.<用户名>.meta` | 成就、累计记录等元数据 |
| `prankTeacher.v7.<用户名>.run` | 金币、道具、陷阱、课节等局内进度 |
| `prankTeacher.v7.<用户名>.extra` | 补课模式、老师轮换位置 |
| `data_<用户名>` | 便于导出/调试的进度镜像 |

* 首次登录 v0.7 时，旧版单人存档会**自动迁移一次**给当前账号；之后再新建账号都是干净存档。
* 账号面板里点「切换账号」，回到登录页重新输入用户名即可。切换时页面会刷新，旧账号数据不会被删除。

## 💾 6 位存档码（v0.7）

### 上传

1. 点右上角账号胶囊 → 「上传并生成存档码」
2. 游戏会打包当前**金币、道具、陷阱、进度、成就和补课设置**
3. 生成一个 **6 位数字提取码**，例如 `834271`
4. 存档码会先保存在本机；如果联网，还会以 base64 分片上传到免费公共通道
5. 面板会显示「✅ 已上传云端」，并支持一键复制

### 下载覆盖

1. 在另一台设备/浏览器打开游戏并登录任意用户名
2. 账号面板输入 6 位提取码 → 「下载覆盖」
3. 优先读取本机存档码；本机没有时自动去云端查找
4. 成功后本地进度会被覆盖，并自动刷新页面

### 注意

* 本机存档码**永久有效**；云端存档约保留 **12 小时**。
* 上传内容只包含游戏进度，不包含任何账号密码或个人信息。
* 上传失败（没联网、公共通道繁忙）时，本机存档码仍然可用，只是不能跨设备提取。
* 如果 6 位码被别的玩家用过同一台机器，后上传的会覆盖同码的本机记录；概率很低，重新生成一个即可。

* 22 秒内没放陷阱，老师会吃完饭离开，下次再触发。
* 每节课最多触发一次；普通周末模式与休闲模式不触发。

## 常见问题

**Q：必须联网吗？**A：不需要。游戏本体、账号、存档都在本机。只有「上传存档码到云端」用到网络，失败也不影响本机存档码。

**Q：换电脑后金币还在吗？**A：在本机生成 6 位存档码，到新设备登录后输入提取码即可。注意云端只保留约 12 小时。

**Q：为什么新建账号金币是 0？**A：账号是隔离的。旧版进度只会迁移给首次登录的那个账号，之后新建的账号都是干净开局。想搬进度就用存档码。

**Q：管理后台会改到别人吗？**A：不会。它只修改当前账号的本地数据，面板上会显示当前用户名。

**Q：补课模式和周末在家能同时开吗？**A：不能。补课模式会把场景强制切回教室；关闭补课且处于课间时，才恢复周末在家状态。

**Q：粉笔总是躲不开？**A：看粉笔的落点，提前走开即可。数学老师粉笔更快，建议优先拉开距离。

**Q：告密超时扣 50 太狠？**A：告密只在标准和地狱难度按概率触发；轻松难度不会触发。撑过 30 秒就能白拿一波紧张感。

## 自测流程

想快速验证 v0.7 是否正常，可以按下面的顺序走一遍：

1. **首次登录**：清空浏览器站点数据后打开 `v0.7.html`，确认弹出登录框；空名字应被拒绝；输入名字后进入游戏。
2. **自动登录**：刷新页面，确认不再询问用户名，右上角显示账号胶囊。
3. **账号隔离**：切换账号输入另一个名字，确认金币从 0 开始；切回原账号，原进度还在。
4. **存档码**：账号面板上传存档，记下 6 位码；刷新后在输入框填码下载覆盖，确认金币恢复。
5. **管理后台**：按住 `Shift` 连按三次 `A`，点「+9999 金币」「解锁所有道具」；手机可长按账号胶囊。
6. **七大玩法**：
  * 上课后等待老师轮换、粉笔来袭；
  * 按 `Q` 放粒子光波，观察冷却；
  * 等 QTE 弹出，答对确认 +30；
  * 反复整蛊直到触发告密，观察 30 秒倒计时与超时 -50；
  * 走进食堂，按 `T` 放陷阱，确认爆炸 +100；
  * 开启补课模式，确认收益 ×1.5 且场景在教室。
7. **兼容性**：分别验证课堂、周五、周末在家、休闲模式都能正常开始和暂停。
8. **移动端**：用浏览器设备模拟或真机检查不横向溢出、按钮可点。
